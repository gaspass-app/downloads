# GasPass downloads

This repository only holds the **Android installer files (APK)** for GasPass — a free app for UK gas and heating engineers. There is no source code here.

**Download and install instructions: [gaspass.co.uk](https://gaspass.co.uk/android.html)**

- GasPass is a **free test version**, provided as it is. Check every result and record yourself. See the [terms](https://gaspass.co.uk/terms.html) and [privacy policy](https://gaspass.co.uk/privacy.html).
- **Updating? Never uninstall first** — uninstalling deletes your data. Install the new version over the top.
- Every release is signed with the same key. Signing certificate SHA-256:
  `AF:7A:DA:3E:A3:4E:FD:85:4D:F5:D2:62:88:93:1C:1E:6C:48:BA:AA:99:1A:48:7D:FC:42:1C:0A:13:B8:EF:98`

iPhone: see [gaspass.co.uk/iphone.html](https://gaspass.co.uk/iphone.html) (TestFlight).
